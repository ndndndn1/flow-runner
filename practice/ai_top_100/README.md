# AI_TOP_100 두 마을 오프라인 연습 에이전트

공개 브리프에 착안한 **가상 문제**이며 공식 데이터·도구·평가기준이 아니다. 원본 메일을 다시 읽은 것이 아니라 사용자가 제공한 브리프를 기반으로 만들었다.

## 현장 문제와 목표

교동마을 창고 담당은 감자가 50 kg 있다고 설명하지만 장부는 5상자로 기록한다. 갯마을 담당은 고등어 30 kg을 설명한다. 조합은 감자 40 kg과 고등어 20 kg 주문을 공동 차량(60 kg)에 배정해야 한다. 상자당 무게가 빠져 있으면 확인 질문을 하고, 장부와 발언이 충돌하면 해당 품목을 보류한다.

평가 기준: 재고·차량 한도 위반 0건, 주문 중복 출고 0건, 미해결 충돌 품목 출고 0건, 모든 출고에 장부·발언·주문 근거 연결, 오류 입력 시 실패 결과 반환. 처리량은 검증된 주문 중 FIFO로 완전 주문을 배정한다. 최적 물류·이익 최대화·식품 안전 판정은 이 모의 문제의 목표에 포함하지 않는다.

## 실행

Python 3.12 이상, 저장소 루트에서:

```bash
python -m venv .venv-practice
.venv-practice/bin/python -m pip install -r practice/ai_top_100/requirements.txt
.venv-practice/bin/python practice/ai_top_100/agent.py practice/ai_top_100/normal.json
.venv-practice/bin/python -m unittest discover -s practice/ai_top_100 -v
```

네트워크는 패키지 설치 때만 필요하다. 실행 시 모델 API 키, Docker, MongoDB, OpenLineage collector가 필요하지 않다. 잘못된 입력은 CLI 종료 코드 2, 정상·확인 대기는 0이다. `--output path.json`으로 보고서를 저장한다.

## 구현과 기존 자산 재사용

`workflow.json`: 추출 → 정합성·확인 질문 → 배정 → 최종 검증 DAG.

기존 `flow_runner.workflow`의 DAG 검증, 위상 정렬, JMESPath 바인딩과 `flow_runner.metadata.describe`의 SHA-256 메타데이터 생성 코드를 직접 import한다. 기존 서비스·설정 파일은 수정하지 않는다. 기준 커밋: `be0fcdbec896fe3116150330025a6922ca6da0ec`.

로컬 연습 실행기는 순차 실행하며 단계 입출력을 JSON Schema로 검증한다. 실패 시 후속 단계를 실행하지 않고 출고 목록을 비운다. 모의 실행 trace는 해시·크기·단계 상태를 남기지만 durable outbox, 재시도, HTTP 모듈 계약, OpenLineage 전송을 구현하지 않는다. `workflow.json`은 기존 문법을 검증하는 연습 DAG이고, 바로 운영 runner에서 실행할 수 있는 배포 구성이 아니다.

`agent.py`: 도구를 호출하는 규칙 기반 에이전트 기준선이다. 자연어 추출은 `품목 재고는 N kg입니다.`라는 제한된 문법만 지원한다. 해석 불가능한 발언은 확인 질문을 만들고 전체 출고를 보류한다. 누락 상자 무게는 모의 관계자 응답 `answers`를 조회한다. 답이 없으면 해당 품목을 보류한다. 대회에서 모델 제공이 확인되면 extract/관계자 질의 어댑터를 교체할 수 있지만, 현재 자유 대화 이해 또는 학습 모델 성능을 검증한 것은 아니다. 관계자 응답은 사실이라는 보장 없이 장부와 대조한다.

현재 모든 재고 행은 서로 다른 실물 물량, 관계자 재고 발언은 품목의 전체 합계라는 가정이다. 실제 장부에서 같은 실물 물량의 복제·갱신 기록이 섞이면 이 가정을 바꿔야 한다. 날짜·유효기간·품질·냉장 조건·권한·예약 재고는 실제 인터페이스 확인 후 추가할 필드다.

## 검증 결과

14개 unittest 통과. 정상 입력은 누락 단위를 질문으로 보충한 후 감자 40 kg + 고등어 20 kg을 배정하고 verified=true를 반환한다. 단위 미응답 또는 감자 재고 모순은 감자를 보류하고 고등어 20 kg만 배정한다. 음수, 알 수 없는 단위, 잘못된 단위 답변, 상충 중복 주문, 중복 재고 ID는 failed와 빈 출고를 반환한다. 동일 주문 중복은 정제하며 한 번만 배정한다. 입력 지시 삽입은 실행하지 않고 보류한다. 차량 용량·미등록 품목·출처 위조·물량 변조·중복 및 누락 출고·상태 변조를 검증한다. 같은 입력의 결과와 해시는 동일하다.

`normal-result.json`과 `scenario-results.json`은 실제 로컬 실행으로 생성했다. 이 결과는 작성한 fixture에서의 기능 검증이며 공식 평가 점수나 자연어 추출 정확도 추정치가 아니다.
